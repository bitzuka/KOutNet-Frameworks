# KOutNet Frameworks 

this is free software for the
KOutNet ecosystem. an open-source and
multiprotocol messanger writted in C++ and Qt6

This repository colleects everything around
KOutNet:

1. librares
2. bots
3. web ecosystem
4. tools
and etc..

## Whats inside??

- **assets/..** - assets, icons
- **general-web/..** - all web things
- **general-web/main-web/..** - homepage
- **general-web/tasks/..** - website 
- **general-web/web-chats/..** - fork of element to multiprotocol
- **telegram-bots/..** - telegram bots for KOutNet

> thats for now. in future may be bigger

## Goals

- Become a serious FOSS project
- Create a truly transport-agnostic messenger
- Create easy-to-embed components to forks/other projects
- make your things easier with use KOutNet

## Contributing

Like others KDE apps, contributions are welcom from all. This repository is managed in KDE Invent

* want to contribute code? See he [GitLab wiki page](https://community.kde.org/Infrastructure/GitLab) for a tutorial on how to send a merge request.
* Reporting a bug? Please submit it on the [KON Bugtracking System](https://bugs.koutnet.pw/enter_bug.cgi?format=guided&product=KOutNet). Please do not use the Issues
  tab to report bugs.
* Is there a part of KOutNet that’s not working correctly? See the [Getting Involved in KOutNet tasks](https://tasks.koutnet.pw/help) to see how
  you can help fix the bug!
  
If you get stuck or need help with anything at all, head over to the [KON New Contributors room](https://later) on Matrix. For questions about KOutNet
